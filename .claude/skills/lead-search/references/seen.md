# Все предложенные домены

Одна строка — одна компания: домены через запятую (алиасы одной компании), потом « — »
и описание. Домены пиши как в адресной строке; скрипт сам приведёт к каноническому виду
(`scripts/leads.py norm`: без `www`, кириллица в punycode).

Четыре раздела — четыре разных состояния. Между ними переносит только шаг 1 скилла и только
в одну сторону: из «Добавлены в трекер» в «Удалены пользователем». Остальные разделы
автоматически не меняются.

Всё из всех разделов, кроме просроченных временных отказов, — в список исключений агентов.
