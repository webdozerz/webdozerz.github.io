# Поиск лидов

Лид — это сайт, по которому стоит потратить вечер на концепт. Каждый лишний лид стоит
пользователю времени: он открывает сайт, понимает, что компания мертва или сайт и так
нормальный, и удаляет строку. В прошлом заходе (26.10.2026) он удалил 19 из 27 — почти все
с пометкой «проверить активность» или на конструкторе с нормальным видом. Поэтому
**лучше 8 точных лидов, чем 20 сомнительных.**

## Аргументы и цель

`/lead-search` — обе ниши, все макрорегионы. Можно уточнить словами: `ниша: Фермерские
продукты`, `регион: Урал`, `город: Омск`, `сколько: 10`. Чего нет в аргументах — бери по
умолчанию, не переспрашивай.

**Цель без квоты.** Обычный хороший результат — 8–10 подтверждённых лидов; 15 — верхняя
граница, а не план. Если прошло меньше — так и запиши в отчёте, с причинами отсева. `fit 3`
не добирать ради количества: только если пользователь сам попросил «побольше».

## Бюджет контекста

Поиск — это сотни запросов и выгрузок страниц, в основную сессию они попадать не должны.
- Ищут **субагенты на `model: "sonnet"`**, по одному на макрорегион, параллельно, одним
  сообщением. В основную сессию возвращается только JSON.
- Основная сессия не открывает сайты целиком: технические проверки — `scripts/leads.py`
  (печатает короткую строку на сайт), визуальная — по ссылкам из доказательств.
- Поиск лидов и концепт — разные сессии. После записи в трекер не начинай концепт здесь.

## Шаг 1. Что уже есть

1. Выгрузи трекер: `ArtifactData list`, коллекция `sites`, `query.limit: 1000`, `out_dir`
   в scratchpad (схема и правила записи — `../redesign-concept/references/tracker.md`).
2. Сверь с `references/seen.md`:
   `python3 -I scripts/leads.py seen references/seen.md <out_dir>`. Скрипт печатает три
   списка:
   - **в трекере, но нет в seen** — допиши в «Добавлены в трекер» (лид добавлен вручную или
     другой сессией);
   - **в «Добавлены», но в трекере нет ни одного домена группы** — пользователь удалил:
     перенеси строку в «Удалены пользователем» с датой. Это единственный автоматический
     перенос; разделы отказов при отборе не трогай;
   - **все домены для исключения** — целиком в бриф агентам.
   Временные отказы с вышедшим сроком перепроверки удали из `seen.md` до выгрузки списка.
3. **Насыщение городов** считай по текущей выгрузке: лиды без концепта и без отказа
   (`steps.concept` и `steps.declined` не отмечены). Город с 3+ такими лидами в этот раз не
   ищи, кроме случая, когда пользователь сам его назвал. Отработанные лиды (с концептом)
   город не закрывают.

## Шаг 2. Субагенты

Разбей Россию по `references/regions.md` и запусти 3 субагента (или одного, если задан
регион или город). Каждому — бриф из `references/agent-brief.md`, подставив дату, регион
без насыщенных городов, ниши, число кандидатов (по 6–8 на агента) и полный список
исключений из шага 1. Агент возвращает JSON `{leads, rejected}`.

Сохрани ответ каждого агента в scratchpad и проверь формат:
`python3 -I scripts/leads.py validate <file.json>`. Кандидата без обязательных полей или
без URL доказательств не чини за агента — отказ (`criteria.md`, «Доказательства»).

## Шаг 3. Отбор в основной сессии

Пройди каждого кандидата по `references/criteria.md` в его порядке. Коротко:

1. **Не тот бизнес** — ниша, сеть, франшиза, маркетплейс, подстраница чужого сайта → отказ.
2. **Уже видели** — домен или та же компания под другим доменом (совпали название + город,
   телефон, адрес или ИНН) → отказ. Алиасы одной компании пиши одной строкой.
3. **Megagroup** → отказ. Это коммерческое решение пользователя (04.11.2026), а не
   утверждение, что на платформе ничего нельзя сделать: по таким сайтам правки упираются в
   конструктор, тариф и доступы, и концепт труднее продать в работу.
4. **Мёртвый** — нет проверяемого признака жизни не старше 12 месяцев (сайт, соцсети,
   карточка на картах) → отказ. Сомнение — не пометка «проверить активность», а отказ.
5. **Ошибок для покупателя нет — вето.** Нужен заметный покупателю дефект: цены и единицы
   расходятся, «Купить» в никуда, протухшие акции, заглушки, нет мобильной версии
   (`criteria.md`, «Сайт мешает покупателю»). Вето ставится только после просмотра
   каталога, карточек и доставки — не по движку и не по наличию viewport.

Техническую проверку сделай одним вызовом на всех прошедших:
`python3 -I scripts/leads.py check <url> <url> …`. Он делает GET с редиректами и печатает
код, итоговый адрес, title, viewport, маркеры платформ и статус:
- `ok` — сверь title с компанией и `platforms` с правилом про Megagroup;
- `parked` / `dead` — отказ;
- `unreachable` — у домена нет DNS: отказ «не открылся» (временно);
- `no_connect` — DNS есть, соединения нет. Часто это не мёртвый сайт, а блок иностранных IP:
  при включённом VPN (немецкий выход) .ru-сайты не открываются ни из curl, ни из WebFetch,
  ни из браузеров. Не отказ и не запись в `seen.md` — отложи в отчёт списком «проверить без
  VPN»;
- `manual_check` — сайт мог закрыться от ботов: открой его в браузере
  (`mcp__Claude_Browser__navigate` + `get_page_text`, не скриншот) и реши по виду. Не отказывай
  только из-за ответа скрипта.

Визуальное вето проверь по `why_evidence`: если в доказательствах нет ни одного дефекта,
который видно глазами (только jQuery, HTTPS, кодировка), открой главную в браузере на
мобильной ширине и посмотри. Остальные факты агент уже проверил — не перепроверяй всё заново.

## Шаг 4. Запись в трекер

1. Одним `batch` (`set`, без `if_version` — документы новые). Поля: `name`, `url`, `city`,
   `niche`, `platform`, `fit`, `order`, `why`, `contact`, `proof`. `check` не ставь —
   сомнительных уже отсеяли. `order` — продолжай с максимума в нише.
   - `proof` — `{"alive_date": "2026-10-12", "alive_url": "…", "alive_type": "пост в VK",
     "contact_url": "…"}`: страница показывает его ссылкой «жизнь: 12.10.2026», чтобы
     пользователь проверил одним кликом.
   - `contact` — только из официальных источников компании (`criteria.md`, «Контакты»);
     не нашлось — пусто, не угадывай адрес по шаблону.
2. **До пяти лучших** — `top: true` и `topWhy` одной строкой: почему концепт по нему легко
   продать. Только тех, кто действительно подходит (`criteria.md`, «Лучшие»), не добирай до
   пяти.
3. Обнови `references/seen.md`: добавленных — в «Добавлены в трекер»; отказанных на шагах 2–3
   и в `rejected` агентов — в «Отклонены при отборе — постоянно» или «… — временно» по причине
   (`criteria.md`, «Куда записать отказ»), с датой.

## Шаг 5. Отчёт пользователю

Коротко, без таблиц на весь экран:
- сколько добавлено по нишам и откуда (города); если меньше 8 — почему;
- лучшие одной строкой каждый: компания, город, чем зацепит;
- сколько отсеяно и по каким причинам в основном («мёртвые — 6, Megagroup — 3, ошибок нет
  вид — 4»), и сколько ушло на ручную проверку;
- ссылка на трекер: https://claude.ai/artifact/LEwiDXTP1gqtPoPv5YrxSp

Концепт по лиду — в новой сессии: кнопка «Взять в работу» в трекере копирует команду.
