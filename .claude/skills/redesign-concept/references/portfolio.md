# Реестр облика концептов

Концепты живут рядом в каталоге `/redesign/`. Два магазина одной ниши в одном шаблоне с
разным логотипом читаются как «штампует под копирку». Структура ниши (блоки, функции)
может повторяться, облик — нет. Сверяйся с реестром ДО брифа, вноси концепт ПОСЛЕ публикации.

## Оси облика

Палитра (акцент + тёмный + поверхность) · Шрифт (`visual-direction.md`) · Шапка H ·
Первый экран (буква) · Карточка K · Форма (острые 2–4 / мягкие 8–12 / круглые 16–24) ·
Мобильная навигация M · Фирменная деталь. Полный список кодов — только в `layouts.md`;
новый код добавляй туда же, здесь диапазоны не перечисляй.

**Зацепка первого экрана** (с 09.11.2026) — девятая ось, список ниже таблицы: приём не повторяется у двух
концептов подряд (`visual-direction.md`).

**Правило отличия.** От КАЖДОГО концепта той же ниши — минимум по пяти осям из восьми,
от любого — минимум по трём. Шрифт и первый экран не повторяются у двух концептов подряд.

## Как вносить новый концепт

После публикации — строка в таблицу. Совпавшую ось пометь «ПОВТОР» и коротко почему это
оправдано. Оценку пользователя («эталон», «не понравилось») — в «Деталь». Технические уроки,
найденные по ходу, — в `lessons.md`, не сюда.
