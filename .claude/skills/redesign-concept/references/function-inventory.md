# Инвентарь функций оригинала

Цель — ничего не потерять. В sttorg70 после первого прохода пропали выбор количества
в карточках, отзывы, избранное, вход, «Купить сейчас» — пользователь заметил сам, и
это стоило отдельной итерации. Инвентарь делается до вёрстки и попадает в бриф.

## Как собирать

Пройди каждый тип страницы и запусти в странице (chrome-devtools `evaluate_script`):

```js
() => {
  const vis = e => e.offsetParent !== null
  const txt = e => (e.innerText || e.value || e.placeholder || e.title ||
    e.getAttribute('aria-label') || '').trim().replace(/\s+/g, ' ').slice(0, 60)
  return {
    controls: [...document.querySelectorAll('a,button,input,select,textarea')]
      .filter(vis).map(e => `${e.tagName}|${e.name || ''}|${txt(e)}`).slice(0, 120),
    tabs: [...document.querySelectorAll('[role=tab], .tabs li, .wc-tabs li')].map(txt),
    forms: [...document.querySelectorAll('form')].map(f =>
      [...f.elements].map(el => el.name || el.type).filter(Boolean).join(',')),
    headings: [...document.querySelectorAll('h1,h2,h3')].map(txt).filter(Boolean).slice(0, 40),
  }
}
```

Для карточки товара в листинге найди один экземпляр (по кнопке «в корзину») и выведи
его элементы отдельно — там прячутся qty-инпут, wishlist, compare, quick view, варианты.

Скрытые функции (появляются по клику/наведению): открой бургер-меню, наведи на карточку,
открой вкладки товара, нажми «в корзину» и посмотри мини-корзину. Логин/регистрация
часто в модалке или в шапке иконкой.

## Чек-лист: что проверить всегда

Шапка и навигация
- [ ] поиск (есть ли выбор категории, подсказки)
- [ ] **каталог: что происходит по клику/наведению на «Каталог»** — мега-меню, выезжающее
      дерево, список. Если у магазина больше одного уровня категорий, раскрывающийся
      каталог переносится ВСЕГДА: на десктопе разделы слева и подразделы справа, на
      телефоне — полноэкранный список с переходом по уровням и «Назад». Заказчик от
      этого не откажется, это базовая навигация. Дерево собери скриптом из ссылок меню
      (родитель → дети) и сверь с тем, что видно после клика
- [ ] вход / личный кабинет, регистрация
- [ ] избранное (счётчик), сравнение (счётчик)
- [ ] мини-корзина: сумма, количество
- [ ] телефон, мессенджеры, режим работы, город

Листинг / каталог
- [ ] выбор количества прямо в карточке (особенно опт, весовой товар)
- [ ] единица (кг, шт, упаковка), шаг количества, минимальная партия
- [ ] варианты (фасовка, «с НДС / без НДС», размер) — кнопка «Выберите параметры»
- [ ] метки: новинка, акция, остаток, хит
- [ ] старая цена, скидка
- [ ] сортировка, фильтры, число товаров, пагинация / «показать ещё»
- [ ] быстрый просмотр, избранное и сравнение на карточке

Карточка товара / услуги
- [ ] галерея, наличие/остаток, артикул, характеристики, описание
- [ ] количество + «В корзину», «Купить сейчас» / «В 1 клик»
- [ ] отзывы: список, рейтинг, форма (часто только для вошедших)
- [ ] вопросы-ответы, похожие товары, «с этим покупают»
- [ ] доставка/оплата кратко прямо в карточке

Корзина и оформление
- [ ] изменение количества, удаление, пересчёт
- [ ] порог бесплатной доставки, стоимость доставки, зоны
- [ ] купон / промокод
- [ ] тип покупателя (физлицо / юрлицо, реквизиты)
- [ ] способ доставки и оплаты, время, комментарий

Прочее
- [ ] объявления (повышение порога доставки, праздники) — у локального бизнеса это часто
      самое важное сообщение на главной
- [ ] новости / блог, акции отдельной страницей
- [ ] формы: обратный звонок, заявка, запись на время
- [ ] QR / ссылки на группы (Telegram, Max, VK, WhatsApp)
- [ ] документы, реквизиты, ИНН (указывает на ИП/ООО — пригодится для письма)

## Как переносить

| Ситуация | Решение |
|---|---|
| Функция есть и важна для ниши | Перенести и сделать рабочей на моках |
| Функция устаревшая (сравнение в продуктовом, quick view, выбор категории в поиске) | Можно не переносить, но назвать в брифе и в итоговом ответе |
| Функции нет, но это best practice ниши | Добавить как идею, в письме пометить «идея, обсуждается отдельно» |
| Функция требует сервера (оплата, логин, отправка формы) | Интерфейс + честное демо-сообщение («Это демо: код не отправляется») |

Моки: отзывы — 2–4 правдоподобных отзыва с датами, без выдуманных фамилий и без
утверждений, которые могут оказаться ложью о товаре. Форма добавляет отзыв локально
с пометкой «виден только вам».
