# Молочный завод / производитель с доставкой своей продукции
Проект: `fermertomska` (Nuxt, InSales, 27 позиций, 22.10.2026). Общее для продуктов — `grocery.md`.
Эталоны: ВкусВилл (карточка с жирностью и сроком хранения), «Молочное хозяйство» и фермерские
доставки с расписанием по дням.

Обязательные блоки
- «Когда привезут»: правило «заказ до 15:00 → доставка в день Х» считать по дню недели и
  часовому поясу города (`Intl.DateTimeFormat` с `timeZone`), районы с отдельными днями —
  переключателем. В корзине — выбор дня из ближайших 3–4.
- Порог бесплатной доставки шкалой в корзине; совет владельца «объединяйтесь с соседями» —
  рядом со шкалой, это его голос.
- Короткий срок хранения (5 суток) — аргумент натуральности, показать в карточке и в «О заводе».
- Награды (медали масла) — отдельным блоком с фото продукта, а не строкой в тексте.
- Самовывоз со своим минимумом заказа — предупреждение и неактивная кнопка, а не ошибка оформления.

Карточка
- Фасовки одного продукта (200/450 г, 300 г/1 кг, вкусы йогурта) — одна карточка с чипами;
  у InSales-магазинов каждая фасовка заведена отдельным товаром.
- Жирность — цветная метка цветом этикетки упаковки; в названии её не повторять.
- Весовые полуфабрикаты — «за кг», счётчик в кг, пометка «итог уточним при сборке»;
  количество не больше остатка.
- Пометки владельца («Изменился объём») — плашкой в карточке, не терять.

Мобильное: таббар с суммой корзины; снимок линейки не обрезать (3:2 без `cover`-кропа),
иначе точки съезжают с продуктов.

Частые ошибки оригиналов: нет разделов по продуктам (меню из «Новинки/Хиты/Акции»),
обязательная регистрация при оформлении, общие фото на разные фасовки, демо-тексты шаблона
на служебных страницах, нет фото самого производства.
