# Фермерские продукты, здоровая еда, маленькие магазины на Taplink / в соцсетях
Проект: `foodgood` (Taplink, 111 товаров одной лентой без разделов).
- **пересчитай ассортимент перед правкой**: у Taplink-магазина лента грузится внутри прокручиваемого
  контейнера — `window.scrollTo` подгружает 12 позиций из 111, крути сам контейнер. Первая версия
  концепта потеряла 96 товаров именно так
- разложи ленту по разделам (фрукты, заморозка, рыба, мясо и дичь, полуфабрикаты, мёд и чай…) —
  для такого магазина это главный выигрыш, который владелец сразу увидит; поиск с подсказками
- «Сейчас в сезоне» на первом экране — поставки сезонные, лента меняется (лето — клубника, осень —
  клюква, хурма)
- происхождение из названия («Киргизия», «Мурманск», «Парабель») меткой на фото
- мессенджеры — основной канал заказа: корзина отдаёт заказ текстом; в концепте — только копирование,
  без ссылки на настоящий номер
- отзывы на виду, условия «заказ на сегодня до 18:00» в шапке
