# Варианты раскладки

Набор проверенных вариантов для ключевых зон. Выбирай по бизнесу клиента (что
покупатель делает первым), а затем сверяйся с `portfolio.md`, чтобы не повторить
недавний концепт. Комбинации свободные: шапка H3 + первый экран D + карточка K4 — это
уже совсем другой магазин, чем H1 + A + K1.

## Шапка

| Код | Как выглядит | Когда |
|---|---|---|
| H1 | Светлая строка: логотип, кнопка «Каталог», широкий поиск, иконки с подписями; под ней лента категорий | универсально, много категорий |
| H2 | Тёмная/цветная полоса бренда с теми же элементами; лента категорий светлая | сильный цвет бренда, логотип для тёмного фона |
| H3 | Поиск — главный элемент: крупное поле на всю ширину второй строкой, подсказки с фото и ценой, частые запросы чипами | большой каталог (1000+ позиций), покупатель знает, что ищет (опт, запчасти) |
| H4 | Минимальная: логотип по центру, меню слева, корзина справа; категории только в выезжающем меню | маленький ассортимент, акцент на бренд (цветы, кондитерская, ферма) |
| H5 | Две строки: верхняя — город, телефон, режим работы, «Для бизнеса»; нижняя — логотип, мега-меню категорий кнопками, корзина | B2B, где важно позвонить и где каталог разбит на крупные разделы |

## Первый экран

| Код | Как выглядит | Когда |
|---|---|---|
| A | Крупный промо-баннер слева + 2 малых справа, ниже полоса преимуществ | ритейл с акциями и условиями доставки |
| B | Полноширинное фото/коллаж продукции с заголовком поверх и одной кнопкой | сильная фотография товара или производства |
| C | Витрина категорий сразу: сетка 8–12 крупных плиток вместо баннера, над ней короткий заголовок | покупатель приходит за конкретной категорией, акций мало |
| D | Поиск по центру экрана + популярные запросы + 3–4 цифры о компании | большой оптовый каталог, постоянные клиенты |
| E | Слайдер акций на всю ширину + под ним «быстрый заказ» (последние заказанные / хиты) | много акций, повторные покупки |
| F | История: фото людей/хозяйства, факты о происхождении, затем товары | фермы, ремесленные производства, семейный бизнес |
| G | Сплит: слева выгоды и форма заявки (опт, договор), справа витрина товаров | B2B, где цель — заявка, а не корзина |
| H | Сцена-карусель: панель обычной высоты, товары едут по дуге вместе с прокруткой, наверху — сами по таймеру; фон меняет тон раздела | у оригинала уже есть сильный приём с движением, крупный опт с брендами без фото (sibirtreid) |
| I | Сплит: панель с девизом, поиском и частыми запросами ↔ сетка 2×2 крупных фото «сейчас в сезоне» с плашкой «название · цена · +» | сезонный ассортимент, магазин без разделов у оригинала (foodgood) |
| J | Сплит: панель с девизом и живым «когда привезут» ↔ один общий снимок всей линейки с точками на продуктах; по нажатию — карточка «фасовка · цена · +», на телефоне карточка под снимком | у производителя есть хорошая общая фотосессия продукции, ассортимент до 30 позиций (fermertomska) |

## Карточка товара в листинге

| Код | Как выглядит | Когда |
|---|---|---|
| K1 | Фото в рамке, цена над названием, счётчик + кнопка | универсально |
| K2 | Фото на цветной подложке без рамки, кнопка-плюс в углу фото, после нажатия счётчик на фото | продуктовый ритейл, похож на приложения доставки |
| K3 | Горизонтальная строка: маленькое фото, название, фасовка, цена за единицу и за упаковку, количество — списком | опт и прайс-лист: покупатель сравнивает и набирает много позиций |
| K4 | Крупное фото во всю карточку, текст поверх нижней части, кнопка «Выбрать» | цветы, торты, подарки — покупают глазами |
| K5 | Карточка с переключателем вида «плитка / список» у каталога | большой каталог, где одни ищут глазами, другие по списку |

## Мобильная навигация

| Код | Как выглядит | Когда |
|---|---|---|
| M1 | Нижний таббар 4–5 пунктов с корзиной | магазин с корзиной |
| M2 | Плавающая кнопка корзины с суммой внизу справа + бургер в шапке | мало разделов, короткие сессии |
| M3 | Липкая нижняя панель «Позвонить / Написать / Заявка» | услуги, B2B без корзины |
| M4 | Липкий поиск сверху + нижний таббар из 3 пунктов | большой каталог |
| M5 | Бургер + поиск второй строкой шапки, нижняя полоса корзины «N · сумма · Оформить» появляется с первым товаром | небольшой магазин, где поиск важнее разделов (foodgood) |

## Форма и плотность

- **Острые 2–4 px, плотная сетка** — только для мелочей (метки, таблицы прайса) в опте
  и B2B. Карточки, кнопки и панели с острыми углами пользователь отверг на tomich
  («слишком острые»): минимум для кнопок — 8–10 px, для карточек и панелей — 14–18 px.
- **Мягкие 8–12 px** (кнопки) **+ 16–18 px** (карточки, панели) — универсальный ритейл и еда.
- **Круглые 16–24 px, воздух** — доставка еды, цветы, кондитерские.

Плотность тоже отличает: опт выигрывает от плотных списков (K3), ритейл — от воздуха.
